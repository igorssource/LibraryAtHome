# Домашняя библиотека

Семейная библиотека как простой сайт: карточки книг с обложками, поиск по названию и автору (также латиницей), выбор жанров.

**Сайт:** https://igorssource.github.io/LibraryAtHome/

- `home-library/`: сайт и данные (`books-data.js`).
- `.claude/skills/add-books/`: рутина добавления книг по фотографии корешков (для Claude Code).
- `.github/workflows/`: автоматическая публикация сайта на GitHub Pages.

Новые книги добавляются через Claude Code: достаточно отправить фото полки.
